# Опубликовать игру и включить VIP

Готовое место уже содержит карту, серверные скрипты и интерфейс. Здесь нужны
действия в вашем Roblox Studio и Creator Hub. Пароли, cookie и токены присылать не нужно.

## 1. Опубликовать место

1. Откройте `build/QuarterHeroes.rbxl` в Roblox Studio.
2. Выберите **File → Publish to Roblox**.
3. Создайте новую игру со своего аккаунта или своей группы. Например,
   назовите её **«Герои квартала»**.
4. После публикации откройте настройки места и поставьте максимум **6 игроков**.
5. Для локальной проверки DataStore включите **Game Settings → Security → Enable Studio Access to API Services**.
6. Запустите Play, постройте этаж, откройте ящик, остановите игру и запустите снова.
   Монеты, этаж и оружие должны восстановиться. Займите любой свободный участок.
7. Проверьте игру двумя клиентами через **Test → Server & Clients** по чек-листу README.
8. Откройте доступ игрокам в Creator Hub, когда проверка закончена.

## 2. Создать настоящие Game Pass

В этом проекте подготовлены **косметические** пропуска. Бесплатные ящики с
оружием доступны всем игрокам; VIP не меняет шансы и боевой урон.

1. Откройте [Creator Hub](https://create.roblox.com/).
2. Выберите вашу опубликованную игру в **Creations → Experiences**.
3. Перейдите в **Monetization → Passes** и нажмите **Create a Pass**.
4. Создайте первый пропуск:
   - Название: **Клуб героев VIP**.
   - Описание: **Золотой титул «КЛУБ ГЕРОЕВ» над персонажем. Косметический бонус без усиления урона.**
   - Загрузите своё изображение; его наличие требует Creator Hub.
5. Создайте второй пропуск:
   - Название: **Неоновый арсенал**.
   - Описание: **Светящийся неоновый след на оружии героя и оружии из ящиков. Косметический эффект.**
6. В настройках продаж каждого пропуска включите продажу и задайте цену.
   Для первого запуска можно рассмотреть **49 Robux** за VIP и **79 Robux** за
   неоновый эффект; окончательные цены задаёте вы. Roblox показывает покупателю свою актуальную цену.
7. Скопируйте **ID пропуска**, а не ID картинки и не ID игры.

## 3. Вставить ID в Studio

1. В Explorer откройте **ReplicatedStorage → Shared → TycoonConfig**.
2. Это **ModuleScript**, уже существует: второй создавать не нужно.
3. Найдите таблицу `GamePasses` ближе к концу настроек.
4. У строки `VIP` замените только `Id=0` на ID первого пропуска.
5. У строки `Neon` замените только `Id=0` на ID второго пропуска.
6. Снова выполните **File → Publish to Roblox**.
7. В опубликованной игре в магазине появятся кнопки покупки. Нажатие открывает
   стандартное окно Roblox; отмена ничего не выдаёт. Сервер подтверждает
   владение пропуском через MarketplaceService и восстанавливает эффект при входе.

Пока ID равен 0, покупка отключена. В тестовом Studio панель владельца позволяет
посмотреть VIP-титул и неоновый след без покупки. Это предпросмотр, он не создаёт
настоящий Game Pass и не записывает владение в Roblox.

## 4. Панель владельца

После публикации панель автоматически доступна создателю игры; для игры группы —
владельцу группы с рангом 255. Выдавать дополнительные права необязательно.

Чтобы разрешить конкретного помощника, в том же **TycoonConfig** найдите
`AdminUserIds={}` и добавьте его числовой Roblox UserId. Сервер проверяет
разрешённый список, а не присланный клиентом флаг. Не добавляйте чужие ID случайно.

Команды: добавить себе 25 000 монет, восстановить своё здоровье, вернуться к
своему дому. Для неопубликованного Studio тестовые игроки получают панель,
чтобы удобно проверить дорогие улучшения. Это правило не действует в живом сервере.

## Что ещё требует Roblox

Облачная сборка не запускала Studio, не публиковала игру и не создавала настоящие
пропуска: здесь нет авторизованного подключения к вашему Creator Hub. Реальные
сохранения, покупки, физика и сетевой бой требуют проверки в Roblox.

Доход и количество игроков зависят от качества тестирования, удержания,
оформления страницы и продвижения. Код подготовлен для запуска, но продажи
или популярность не гарантируются.
