# Проверить и опубликовать QuarterHeroes

Ветка обновления: **release/quarter-heroes-polish**.
[Готовый файл](https://github.com/rintex/roblox-game/raw/refs/heads/release/quarter-heroes-polish/build/QuarterHeroes.rbxl)
уже включает карту, текстуры материалов, серверные модули и интерфейс.
Roblox Studio и авторизованный Creator Hub в облаке недоступны;
публикация, реальные пропуска и покупки здесь не выполнялись.

## 1. Проверить в Studio

1. Откройте файл через **File → Open from File**.
2. Нажмите **Play**, откройте **View → Output**.
3. Пройдите обучение, постройте три этажа, наденьте и снимите костюм,
   попробуйте бой, оружие, ящик и обби.
4. Через **Test → Server & Clients** запустите **6 клиентов** и проверьте
   владение участками, одновременные покупки, один приз на общий ящик, PvP и выход.
5. Выполните [план ручных испытаний](docs/STUDIO_TEST_PLAN.md), включая телефон,
   планшет, геймпад, сохранения, права владельца и измерение нагрузки.

Неопубликованное Studio использует режим одной сессии: он явно показан в HUD.
Для проверки настоящего DataStore опубликуйте закрытый тестовый experience,
включите **Game Settings → Security → Enable Studio Access to API Services**,
затем проверьте несколько запусков и входов. У тестового experience отдельная
область данных; основные сохранения переносить или удалять для проверки не нужно.

## 2. Настроить experience

1. Выберите **File → Publish to Roblox** и свой аккаунт или группу.
2. Установите у стартового Place **Max Players = 6**: в игре шесть участков.
3. Проверьте загрузку профиля и повторный вход в опубликованном тестовом сервере.
   После входа займите свободный участок — сохранённый дом восстановится.
4. Выполните проверки сохранения после смерти, перерождения, выхода и остановки
   сервера. Оставьте `HouseTycoon_v1` и формат `Version = 1` без изменения.
5. Проверьте страницу игры, возрастные сведения, права на название и оформление.
6. Открывайте публичный доступ после прохождения обязательных ручных проверок.

Если редактируете исходники, сначала выполните `npm run build` и `npm test`,
затем открывайте полученный rbxl. Если меняете код внутри Studio, переносите
те же изменения в исходники перед следующей облачной сборкой.

## 3. Подключить косметические Game Pass

Оба пропуска косметические: **Клуб героев** — золотой титул,
**Неоновый арсенал** — след на оружии. Они не усиливают урон, доход или
шансы ящиков. Бесплатные титулы достижений не требуют Game Pass.

1. В [Creator Hub](https://create.roblox.com/) откройте опубликованный experience:
   **Creations → Experiences → Monetization → Passes**.
2. Создайте два пропуска, добавьте свои изображения и описания, настройте продажу
   и цену. Цену покупатель видит в стандартном окне Roblox.
3. Скопируйте **Game Pass ID**, а не ID experience или картинки.
4. В Explorer откройте существующий **ModuleScript**
   **ReplicatedStorage → Shared → TycoonConfig**.
5. В таблице `GamePasses` в строке `VIP` замените её `Id=0` на ID первого
   пропуска, в строке `Neon` — на ID второго. При работе с репозиторием тот же файл —
   `src/shared/TycoonConfig.luau`; пересоберите место.
6. Опубликуйте обновлённый Place.
7. Проверьте отмену покупки, успешное серверное подтверждение владения и
   восстановление косметики после повторного входа в опубликованном experience.

Пока ID равны **0**, платные кнопки скрыты и покупка не открывается.
Событие закрытия окна само по себе ничего не выдаёт: сервер обращается к
`UserOwnsGamePassAsync`. Кнопки предпросмотра VIP/Neon в админ-панели работают
только в Studio и не создают право владения пропуском.

## 4. Проверить панель владельца

После публикации доступ имеют создатель experience, владелец группы с рангом 255
и числовые UserId из `AdminUserIds` в TycoonConfig. Клиентский флаг
`IsGameAdmin` не даёт полномочий.

Панель открывается через **Меню → Панель владельца**.
Команды действуют на самого владельца: +25 000 монет, лечение, возврат к дому.
Возврат домой отклоняется во время активного обби: сначала завершите маршрут
или нажмите его кнопку выхода. В неопубликованном Studio все локальные тестовые
игроки получают панель; в живом сервере это исключение не действует.

## 5. Оформление для коммерческого выпуска

В текущей ветке сохранены ранее выбранные персонажи Marvel. Их поверхности
нарисованы процедурно, но это не подтверждает права на имена, образы и символы.
Проверка разрешений и лицензий не проводилась.

Для самостоятельного оформления можно сохранить внутренние ID и заменить
названия, силуэты, символы, палитры, способности и описание истории:

| Стабильный ID | Предлагаемый герой | Самостоятельное визуальное направление |
|---|---|---|
| `arachna` | Нитник | Мятные кинетические нити, тканевая маска с геометрическим визором; без паучьего символа |
| `nightweaver` | Сумрак | Тёмный плащ-панцирь, янтарный визор и дроны-тросы; собственная эмблема |
| `volt` | Вектор | Белая керамическая броня, оранжевые энергоканалы, асимметричный ранец |
| `titan` | Базальт | Каменные перчатки, охристая экипировка и сейсмическая способность |
| `frost` | Север | Голубая техническая куртка и полярный излучатель; без узнаваемого молота и плаща |
| `helios` | Гелиос | Солнечные панели на плечах, коралловое ядро и световое копьё |

Это предложения для следующей художественной версии, а не уже выполненная
замена или заключение о правах. Одного переименования недостаточно.
Сохранение ID защищает связи инвентаря и прокачки со старыми профилями;
стили в VisualStyle, HeroWorld, HeroCombatService и UITheme также нужно обновить.

Не добавлялись чужие опубликованные анимации или сторонние модели со скриптами.
Звуки и частицы используют встроенные пути Roblox. Если встроенный звук
не воспроизводится на устройстве, игра продолжает работать без него.
Фирменная музыка и проверка аудио на всех устройствах остаются отдельной задачей.

## Статус выпуска

Автоматические проверки подтверждают логику в облаке и состав сборки.
Они не подтверждают реальные DataStore/Marketplace API, физику, сеть, FPS,
читаемость на устройствах или готовность к публичному выпуску.

Ручные проверки ещё не отмечены как пройденные. Опубликованный experience,
настоящие ID Game Pass, проверка лицензий и финальная настройка страницы игры
пока не выполнены.
