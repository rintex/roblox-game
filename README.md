# Домики: Roblox House Tycoon

Готовый небольшой тайкун с четырьмя участками и домами, которые игрок строит
последовательно: первый, второй и третий этажи. Третий этаж открывает золотой
генератор, балкон, бонусный сундук и ускорение персонажа.

## Открыть готовую игру

1. [Скачайте HouseTycoon.rbxl](https://github.com/rintex/roblox-game/raw/refs/heads/main/build/HouseTycoon.rbxl).
2. В Roblox Studio нажмите **File → Open from File** и выберите скачанный файл.
3. Нажмите **Play**. Карта и четыре участка уже включены в файл.
4. Подойдите к зелёной площадке **«Занять»** на свободном участке. Удерживайте
   **E** на компьютере или экранную кнопку на телефоне.
5. Подойдите к синей площадке **«ЭТАЖ»** и постройте первый этаж за **50 монет**.
   У нового игрока есть **75 монет**.
6. Генератор начнёт наполнять копилку. Забирайте монеты на зелёной площадке
   **«КОПИЛКА»**, а затем покупайте следующие этажи.
7. Фиолетовая площадка **«ГЕНЕРАТОР»** улучшает доход. Кнопка **«Магазин»** в HUD
   показывает цены и подсказывает, к какой площадке подойти.
8. После третьего этажа поднимитесь по внешним лестницам и откройте золотой
   сундук. Он даёт **120 монет и 15 XP раз в 60 секунд**.

Площадки покупок находятся перед домом. На второй этаж ведёт первая лестница
и задняя дверь; на третий — соседняя лестница и боковая дверь. Дом перестраивается
сразу после покупки, а уведомление показывает результат.

| Улучшение | Цена | Базовый доход дома |
|---|---:|---:|
| Первый этаж | 50 | 5 монет/сек |
| Второй этаж | 200 | 14 монет/сек |
| Третий этаж | 600 | 52 монеты/сек с бонусом третьего этажа |

Три улучшения генератора стоят **60, 140 и 320 монет**. Каждое добавляет 50%
от базового дохода. Максимальный доход полностью улучшенного трёхэтажного дома
— **131 монета/сек**. Доход накапливается, пока игрок находится в игре и владеет
участком. Покупки оплачиваются монетами в кошельке: сначала заберите накопления
из копилки.

За собранные монеты начисляется XP. Каждые 100 XP увеличивают Level на один.
На третьем этаже скорость персонажа увеличивается с 16 до 24 и сохраняется
после возрождения в текущей игровой сессии.

## Сохранение прогресса

В локальном неопубликованном файле Studio включается **тестовый режим без
сохранения**. HUD прямо сообщает: «прогресс только в этой сессии».

Чтобы включить постоянное сохранение:

1. Опубликуйте место через **File → Publish to Roblox**.
2. Для проверки сохранений в Studio откройте **Game Settings → Security**,
   включите **Enable Studio Access to API Services** и сохраните настройки.
3. Запустите Play, постройте дом, заберите монеты и нажмите Stop.
4. Снова запустите Play и займите свободный участок: этажи, кошелёк, XP,
   улучшения генератора, копилка и задержка сундука должны восстановиться.

В опубликованной игре DataStore работает на сервере. Автосохранение выполняется
раз в 60 секунд, а финальное — при выходе игрока и закрытии сервера. Сессия
блокируется через UpdateAsync, чтобы два сервера не перезаписали один профиль.
При ошибке загрузки в настоящем сервере покупки отключаются, а старое сохранение
не заменяется стартовым. В Studio при недоступном API действует явно обозначенный
режим одной сессии. Ошибка сохранения видна в HUD.

Подготовлено четыре участка. Для опубликованного места установите максимум
**4 игрока** либо добавьте участки отдельным изменением.

## Проверка в Studio

- В Play займитесь постройкой: 75 → 25 монет после первого этажа; копилка растёт.
- Заберите деньги, улучшите генератор, купите второй и третий этажи по очереди.
- Пройдите обе лестницы; откройте сундук, сразу повторите: второй бонус должен
  ждать 60 секунд. После смерти скорость возвращается к 24 при построенном третьем этаже.
- В **Test → Server & Clients** запустите двух игроков. Каждый занимает отдельный
  участок. Попытка получить деньги или купить этаж в чужом доме должна отклоняться.
- Проверьте отсутствие красных ошибок в **View → Output** и восстановление профиля
  после повторного запуска с включённым API.

Покупки и начисления проверяет сервер: владелец, готовность профиля, живой
персонаж, расстояние, задержка действия, цена и баланс. Клиент не отправляет
суммы наград, цены или номера этажей. Локальные капли генераторов только украшают
карту и не создают монеты. Это базовая защита; физическое движение и поведение
в настоящем Roblox проверяются отдельно в Studio.

## Сборка в облаке

```bash
cd /workspace/roblox-game
npm run build
npm test
```

Установка инструментов при необходимости:

```bash
cd /workspace/roblox-game
bash tools/install-cloud.sh
npm test
```

Используются официальный Rojo 7.7.1 с проверкой опубликованной SHA256 и
luau-web 1.5.0 из lockfile. Сборка получает геометрию из настоящих Luau-исходников
карты и HouseWorld, проверяет повторное создание, три состояния дома и пакует
`build/HouseTycoon.rbxl` и `build/HouseTycoon.rbxlx` вместе с девятью скриптами.

Автоматические проверки выполняют реальную Luau-логику на ограниченной модели
Roblox-объектов: экономика, владение, расстояние, задержки, уровни, ограничения
валюты и 14 сценариев сохранений, включая выход во время загрузки, одновременные
финальные сохранения и конфликт сессий. XML-проверка сверяет классы, иерархию,
скрипты, prompts, HUD и камеру. Эти проверки не запускают Roblox Studio и не
подтверждают доступ к настоящему DataStore или физику персонажа.

Предыдущий первый этап сохранён отдельно: [Stage1.rbxl](build/Stage1.rbxl).
Для новой игры открывайте **HouseTycoon.rbxl**.
