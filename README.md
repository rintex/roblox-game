# Roblox Game

Простой симулятор Roblox, который создаётся по этапам.

## Этап 1: карта и точка появления

Подготовлен только первый этап. Монеты, магазин, уровни и сохранение будут
добавляться отдельно.

### Самый простой способ: открыть готовую карту

1. Скачайте [Stage1.rbxl](https://github.com/rintex/roblox-game/raw/refs/heads/main/build/Stage1.rbxl).
2. В Roblox Studio выберите **File → Open from File** и откройте скачанный файл.
3. Нажмите **Play**. Персонаж должен появиться на бирюзовой площадке.

Карта и скрипт уже включены в файл. Создавать объекты и вставлять код не нужно.
Карта видна до запуска и остаётся после **Stop**. В ней зелёная земля, центральная
площадь, четыре дорожки, восемь деревьев, четыре камня и ограждение.

В **View → Output** ожидается сообщение:
`Этап 1 готов: карта SimulatorMap и точка появления StartSpawn.`
Проверьте ходьбу по карте и отсутствие красных ошибок. Сохраните свои изменения
через **File → Save to File**. Публикация на Roblox выполняется отдельно через
Roblox Studio.

Внутри проекта:

- `Workspace.SimulatorMap` — **Folder** с деталями карты.
- `Workspace.SimulatorMap.StartSpawn` — **SpawnLocation**.
- `ServerScriptService.Stage1Map` — **Script**, который использует эти же детали
  при запуске, не создавая дубликаты.

Также доступна текстовая версия места: [build/Stage1.rbxlx](build/Stage1.rbxlx).

### Если хотите вставить скрипт вручную

Это альтернативный путь для собственного пустого проекта. Если открыли готовый
файл выше, выполнять эти действия не нужно.

1. В Roblox Studio откройте новый проект **Baseplate**. Если уже открыли пустой
   проект для этой игры, продолжайте в нём.
2. Откройте панели **Explorer** и **Output** через меню **View** (Вид).
3. В `Workspace` удалите только стандартный `Baseplate` (тип `Part`), если он
   есть: скрипт создаёт своё основание. Стандартный `SpawnLocation` оставьте.
4. В `ServerScriptService` создайте **Script** с именем **Stage1Map**. Если такой
   Script уже существует, откройте его вместо создания второго.
5. Полностью замените содержимое на код из
   [`src/server/Stage1Map.server.luau`](src/server/Stage1Map.server.luau).
6. Нажмите **Play**. Персонаж должен появиться на бирюзовой площадке среди
   зелёной карты с четырьмя дорожками, восемью деревьями и четырьмя камнями.
7. Пройдите по дорожкам. В Output не должно быть красных ошибок; ожидается
   сообщение `Этап 1 готов: карта SimulatorMap и точка появления StartSpawn.`
8. Нажмите **Stop**. Сгенерированная карта исчезнет: она создаётся заново при
   каждом запуске. Сохраните проект через **File → Save to File** (или
   **Publish to Roblox** для сохранения на Roblox).

Скрипт создаёт `Workspace.SimulatorMap` (тип `Folder`) и детали внутри него.
Он использует существующий единственный `SpawnLocation`, переименовывает его
в `StartSpawn` и переносит в эту папку **на время запуска**. Если точек появления
несколько, Output подскажет, что нужно оставить одну: скрипт не выбирает случайную
и не удаляет ваши точки. Детали с одинаковыми именами используются повторно.

Для ручного пути плагины не нужны. Файл `.server.luau` соответствует объекту
**Script**, а не LocalScript.

### Сборка в облачной среде

Исходник карты: `src/server/Stage1Map.server.luau`.
`default.project.json` связывает его с `ServerScriptService.Stage1Map`.

В подготовленной облачной среде:

```bash
cd /workspace/roblox-game
npm run build
```

Для установки инструментов и повторной сборки:

```bash
cd /workspace/roblox-game
bash tools/install-cloud.sh
```

Скрипт устанавливает зависимости из `package-lock.json` и официальную версию
Rojo 7.7.1 с проверкой опубликованной SHA256. Сборка выполняет Luau-скрипт на
тестовой модели Roblox-объектов, получает геометрию из него и упаковывает её вместе
с исходником через Rojo. Результаты: `build/Stage1.rbxl` и `build/Stage1.rbxlx`.
Список координат отдельно от игрового скрипта не поддерживается.

Облачная сборка и проверка структуры файла не заменяют проверку появления и
движения персонажа в Roblox Studio на Windows или macOS. Облачная Linux-среда
не запускает Roblox Studio.
