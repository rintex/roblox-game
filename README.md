# Roblox Game

Репозиторий для нового проекта Roblox.

## Текущее состояние

Это начальный репозиторий. Исходники игры и настройки сборки ещё не добавлены.
Запустить игру или выполнить её тесты пока невозможно.

## Разработка

Игру запускают и проверяют в Roblox Studio на Windows или macOS.
Облачную среду можно использовать для работы с исходниками Luau и инструментами сборки,
когда они будут добавлены в проект.
