# Герои квартала — обновление QuarterHeroes

Тайкун с шестью просторными домами, героями, агрессивными бандитами, бесплатным
оружием и обби по крышам. Эта ветка обновляет существующую игру: город, интерфейс,
обучение, бой и сохранения. Готовый файл содержит карту и код; добавлять объекты
или загружать текстуры вручную не нужно.

**Сборка проходит облачные проверки. Проверка в настоящем Roblox Studio ещё
не выполнена; публикация и продажи не включены.**

## Открыть игру

1. [Скачайте QuarterHeroes.rbxl из ветки release/quarter-heroes-polish](https://github.com/rintex/roblox-game/raw/refs/heads/release/quarter-heroes-polish/build/QuarterHeroes.rbxl).
2. В Roblox Studio выберите **File → Open from File**, откройте скачанный файл.
3. Нажмите **Play**. HUD покажет монеты, уровень, XP и состояние загрузки.
4. Следуйте подсказке с подсветкой объекта: займите участок, постройте этаж,
   заберите выручку, улучшите генератор, примерьте героя и попадите по бандиту.

Стартовый кошелёк — **75 монет**, первый этаж стоит **50**. Обучение состоит из
шести шагов и выдаёт небольшие награды; выполнение проверяет сервер.
Развитым старым профилям повторное обучение автоматически пропускается.
В неопубликованном Studio явно включён режим одной сессии без сохранения.

Ссылка ведёт на рабочую ветку, а не на `main`. Если вы работаете с исходниками,
актуальные файлы — `build/QuarterHeroes.rbxl` и `build/QuarterHeroes.rbxlx`.

## Играть

| Возможность | Где и как |
|---|---|
| Занять дом | Зелёная площадка свободного участка; E или экранная кнопка |
| Построить этаж / улучшить генератор | Площадки перед своим домом; копилка начисляет доход на сервере |
| Надеть костюм | Наступите на открытый стенд у площади; меняются внешний вид и оружие |
| Выбрать героя / цели / титул | **База** → **Герои / Цели / Стиль** |
| Найти оружие | Откройте приземлившийся бесплатный ящик; результат определяет сервер |
| Прокачать оружие | **Арсенал**: редкость, урон, дальность, кулдаун, уровень и цена следующего улучшения |
| Бой | Портал арены; бандиты преследуют и атакуют, главарь меняет атаки по фазам |
| PvP | Оба игрока вошли через портал и находятся на арене; жилые участки и обби безопасны |
| Обби | Старт **«Крыши квартала»**, 16 этапов; контрольные точки 4 / 8 / 12 |
| Настройки | **Меню**: качество эффектов и звуки; настройки действуют в текущей сессии |
| Панель владельца | **Меню → Панель владельца**; только создатель опыта, владелец группы или разрешённый UserId |

Костюмы временно скрывают обычную одежду и аксессуары. После снятия возвращается
исходный аватар; выбор героя восстанавливается после возрождения и загрузки профиля.

Интерфейс использует общий стиль, плавные окна, реакцию кнопок, понятные карточки
героев и оружия. Одновременно открывается одно окно. Меню настроек не останавливает
сервер: на арене противники продолжают бой.

| Действие | Компьютер | Геймпад |
|---|---|---|
| База | M | Y |
| Арсенал | I | D-pad ↑ |
| Меню | P | D-pad ← |
| Способность | Q / клик экипированным оружием | X / активация оружия |
| Закрыть окно | Backspace / экранный крестик | B |

На телефоне используются экранные кнопки. Разметка подготовлена для разных
ориентаций; фактическую работу устройств проверяйте по [плану Studio](docs/STUDIO_TEST_PLAN.md).

## Прогрессия и награды

- Три этажа стоят **50 / 200 / 600** монет. Доход без генераторных улучшений —
  **5 / 14 / 52** монеты в секунду.
- Пять ступеней генератора: **60 / 140 / 320 / 900 / 2 400** монет. У ступеней
  свои названия и визуальные индикаторы; каждая добавляет 50% базового дохода.
- У оружия героя и найденного оружия отдельные пять улучшений за
  **300 / 800 / 1 800 / 4 000 / 9 000** монет: +25% базового урона за ступень
  и немного меньший кулдаун.
- Семь заданий охватывают выручку, строительство, бандитов, главаря, обби и
  перерождение. Восемь достижений открывают бесплатные титулы.
- Ежедневный цикл: **500 / 600 / 700 / 800 / 1 000 / 1 200 / 1 500** монет.
  Между получениями минимум 24 часа. После седьмого дня цикл начинается заново;
  перерыв больше 48 часов после последнего получения возвращает к первому дню.
- Первое перерождение требует трёх этажей, пяти улучшений генератора и
  **25 000** монет. Каждое даёт +35% дохода; следующее стоит на 25 000 дороже.
- Обби даёт **300 монет и 75 XP раз в пять минут**. Повторные забеги улучшают
  рекорд, но не обходят задержку награды.

Перерождение сбрасывает дом, генератор, копилку и кошелёк до 75 монет.
XP, оружие и его улучшения, открытые герои, задания, достижения и титулы сохраняются.

Ящики бесплатны: первый появляется через 20 секунд, следующие — через случайные
90–180 секунд. Шансы шести оружий: **40 / 28 / 18 / 9 / 4 / 1%**.
Один ящик забирает один игрок. Дубликаты накапливаются до 99 копий,
затем заменяются компенсацией до 100 монет. За PvP монеты и XP не выдаются.

## Город, бой и эффекты

На карте шесть участков **66 × 66 studs**, дома **42 × 36** с тремя этажами.
Добавлены крыши и фасады, окна, интерьеры, тротуары, разметка улиц, витрины,
клумбы, деревья, фонтан и оформленные зоны старта, героев, арены и обби.
Кирпич, ткань, дерево, камень, асфальт и металл используют материалы Roblox;
рисунки костюмов встроены через SurfaceGui.

У бандитов есть преследование, разделение при движении, замах и восстановление.
Главарь использует обычный удар, ударную волну и рывок в зависимости от здоровья.
Красные зоны предупреждают об атаке. Отступление и выход за пределы опасной зоны
позволяют уклониться. Оружие отличается формой и эффектами; попадания показывают
числа урона, а способности могут замедлять или прерывать NPC.

Эффекты генераторов, строительства, порталов, грузов и побед создаются на клиенте,
ограничены количеством и расстоянием. Режимы **Высокое / Низкое / Выключены**
снижают декоративную нагрузку; важные предупреждения атак остаются.
Если встроенный звук не воспроизводится, игра продолжает работать без него.
Чужие опубликованные анимации и сторонние модели со скриптами не добавлены.

[Предпросмотр рисунков костюмов](build/CostumeSurfaces.svg) формируется из сборки;
это не скриншот Roblox Studio. Замеров FPS на настоящих устройствах пока нет.

## Сохранения, Game Pass и публикация

Хранилище **HouseTycoon_v1**, ключи и формат оболочки **Version = 1** сохранены.
Новые поля нормализуются с безопасными значениями по умолчанию; существующие
монеты, дом, оружие, улучшения и полученные награды не сбрасываются.
Сессии блокируются через UpdateAsync. Ошибка загрузки на живом сервере отключает
изменения профиля, вместо перезаписи начальными значениями.

Два подготовленных Game Pass дают только косметику: VIP-титул и неоновый след.
ID пока **0**: реальные платные кнопки скрыты. Бесплатные титулы достижений
работают отдельно, а купленные эффекты подтверждаются MarketplaceService.

Публикация, создание пропусков, реальные покупки и проверка прав на персонажей
ещё не выполнены. Текущие персонажи Marvel оставлены по ранее выбранному оформлению.
Для коммерческого выпуска в [PUBLISHING.md](PUBLISHING.md) предложены оригинальные
альтернативы с сохранением внутренних ID.

## Исходники и проверка

| Путь в Explorer | Ответственность |
|---|---|
| `ServerScriptService.Stage1Map` | Базовая карта и один SpawnLocation |
| `ServerScriptService.TycoonServer` | Запуск отдельных серверных сервисов |
| `ServerScriptService.Modules` | Геометрия, экономика, ProfileSchema/ProfileService, PlayerJourney, прогрессия, бой, EnemyAI, костюмы, ящики, обби, Game Pass и админ-панель |
| `ReplicatedStorage.Shared` | TycoonConfig и общий модуль UITheme |
| `ReplicatedStorage.TycoonRemotes` | Восемь событий; клиент выбирает действие, сервер проверяет цену, доступ, награду и урон |
| `StarterPlayer.StarterPlayerScripts` | HUD, TutorialHUD, управление, инвентарь, обби, админ-панель и локальные эффекты |
| `StarterGui.TycoonHUD` | Основной ScreenGui |
| `Workspace` | SimulatorMap, TycoonPlots.Plot1…Plot6, HeroCampus, RooftopObby; Airdrops появляются при Play |

```bash
cd /workspace/roblox-game
bash tools/install-cloud.sh
npm run build
npm test
```

Используются проверенный Rojo 7.7.1 и luau-web 1.5.0 из lockfile. Сборка выполняет
настоящий Luau-код генерации в ограниченной модели Roblox-объектов и создаёт
оба актуальных файла места. Тесты выполняют серверную и клиентскую логику
с управляемыми двойниками API; проверка rbxlx сверяет встроенный код с исходниками.
