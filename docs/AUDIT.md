# Аудит QuarterHeroes

Ветка: **release/quarter-heroes-polish**.
Проверены исходники сервисов, правила профиля и наград, клиентские обработчики,
проект Rojo, сборщик и тесты. Roblox Studio и живые API здесь не запускались.

## Подтверждённые исправления

| Проблема | Изменение и проверка |
|---|---|
| Ошибка последнего сохранения могла завершить ожидание раньше доступного бюджета | Повтор Release при остановке; тест временной и постоянной ошибки с ограничением времени |
| Наблюдатели персонажей накапливались при возрождении | Старые commerce-соединения отключаются; 12 замен персонажа в тесте |
| Отложенный запрос прав/владения мог продолжить работу после завершения | Проверка текущего состояния сервиса и токена игрока после yield; тест выхода/Destroy |
| Админ-телепорт конфликтовал с маршрутом обби | Сервер отклоняет возврат домой при ObbyActive |
| Неактивный забег не истекал без нового касания | Редкая серверная проверка срока; тест без посещения следующей крыши |
| Ошибка обновления HUD могла оставить законченный забег активным | Награда фиксируется один раз; очистка маршрута выполняется после попытки синхронизации |
| Перенесённые площадки/невалидное здоровье могли пройти часть проверок | Проверки родительской сцены, сервиса, профиля, владельца и Health > 0; регрессии в серверных тестах |
| Доступность прокачки оружия могла устареть после пополнения кошелька | Клиент следит за Coins.Value с заменой и очисткой обработчиков |

Выдача ящика уже была серверной и однократной; переписывание не потребовалось.
Добавлена проверка ошибки HUD: результат остаётся в авторитетном профиле,
ящик не открывается повторно. Отмена уже выданной награды из-за ошибки интерфейса
создавала бы риск потери предмета, поэтому отката профиля здесь нет.

## Граница доверия

- Покупки, валюта, XP, редкость, владение, урон, кулдауны и награды выбирает сервер.
  Клиент передаёт известную команду/ID или конечную точку прицеливания.
- Промпты и касания повторно проверяют фактическое расстояние, живого персонажа,
  текущую сессию и нужную сцену. Событие клиента не подтверждает покупку.
- PvP требует согласованного входа обоих игроков и нахождения на арене;
  город, обби и защищённое возрождение исключены.
- Новые цели/достижения читают разрешённые серверные поля. Полученные награды
  помечаются без yield; выбранный титул должен принадлежать игроку.
- DataStore использует UpdateAsync и уникальный токен сессии. Неподходящая версия
  не перезаписывается, отказ загрузки в живой игре не создаёт стартовый профиль.
- Админ-команды проверяют серверное разрешение; локальный атрибут не является
  полномочием. Game Pass косметические и подтверждаются MarketplaceService.

Рассмотренные ограничения и гонки проверены автоматическими сценариями.
Движение персонажа и сетевую физику нужно проверять на настоящем сервере.

## Совместимость данных

Имя `HouseTycoon_v1`, ключи игроков и оболочка `Version = 1` не изменены.
Миграция добавляет поля обучения, достижений/титула, ежедневной серии,
первого попадания и побед над главарём. Неизвестные ID и некорректные числа
нормализуются; копирование снимка не связывает таблицы с рабочим профилем.
Развитому прежнему профилю без нового TutorialStep назначается завершённое
обучение, без повторной выдачи его наград.

Нагрузка: AI обновляется с ограниченной частотой; эффекты локальные, с лимитами,
отсечением по расстоянию и очисткой. Дополнительная декорация увеличила сцену:
404 → 704 Parts при пустых участках, 1 472 → 2 222 при шести готовых домах.
Реального замера FPS, памяти и сетевого трафика нет.

Итоговый прогон после завершения изменений: **`npm run build`**, **`npm test`**
и **`git diff --check`** завершились успешно. Оба файла места пересобраны.

восемь RemoteEvent, один Spawn, шесть участков и 16 этапов обби.
Геометрические проверки подтверждают комнаты 42 × 36, 24 ступени высотой
0,5 studs, выравнивание лестничных площадок, высоту BonusPad 26,7,
повторную генерацию без дубликатов и сброс участка в пустое состояние.
Лимиты проверки: до 900 закреплённых Parts с пустыми участками,
до 2 600 при шести трёхэтажных домах.
