# Ручные испытания QuarterHeroes

**Статус: не выполнены в облаке.** Roblox Studio здесь недоступна.
Перед публичным выпуском заполните результаты для своей версии сборки.
Запишите commit, дату, устройство, разрешение, Roblox-клиент и найденные ошибки.

## Подготовка

1. Откройте rbxl из ветки `release/quarter-heroes-polish`, включите Output.
2. Для настоящих сохранений используйте опубликованный закрытый тестовый
   experience с доступом Studio к API. Оставьте имя хранилища `HouseTycoon_v1`.
3. Для сети запустите **Test → Server & Clients → 6**.
4. Проверяйте новую игру и развитый профиль. Для проверки переноса используйте
   профиль прежней версии в том же тестовом experience; не удаляйте текущие данные.

## Устройства и управление

| Среда | Что проверить | Результат |
|---|---|---|
| ПК, 1366×768 и 1920×1080 | HUD, читаемость, мышь, M/I/P/Q, закрытие Backspace, ProximityPrompt E | Не проверено |
| Телефон, около 390×844 | Сенсорные кнопки, джойстик/прыжок, строки текста, прокрутка, здоровье и атака | Не проверено |
| Телефон, около 844×390 | Поворот в бою и открытом меню; окна не скрывают закрытие, текст и кнопки доступны | Не проверено |
| Планшет, около 768×1024, обе ориентации | Обучение, магазин, карточки, уведомления; нет перекрытий CoreGui | Не проверено |
| Настоящий геймпад | Y/↑/←/X/B, GUI-фокус, кнопки покупки и прокрутка, прицел из центра | Не проверено |

Эмулятор Studio проверяет разметку, но не доказывает производительность телефона.
Проверяйте одно открытое окно, переключение между окнами и повторный запуск
LocalScript: обработчики и анимации не должны дублироваться.

## Игровые проверки

- [ ] **Первые 30 секунд:** корректный Spawn, понятное сообщение загрузки,
      подсветка свободного участка; новичок самостоятельно находит покупку этажа.
- [ ] **Обучение:** шесть целей последовательно выполняются реальными действиями;
      каждый бонус выдаётся один раз, шаг сохраняется после выхода.
- [ ] **Загрузка:** во время ожидания покупка недоступна. Ошибка API показывает
      состояние ошибки; старый профиль не заменяется 75 монетами.
- [ ] **Шесть участков:** два клиента одновременно занимают один участок —
      получает один; остальные занимают свои. Седьмого дома нет.
- [ ] **Экономика:** этажи и генераторы списывают указанную цену один раз;
      чужой дом не позволяет купить или собрать. Копилка, XP и лидерстат совпадают.
- [ ] **Строительство:** двери и лестницы проходимы на всех трёх этажах;
      нет застреваний, проваливания, перекрытых окон/площадок или недоступного сундука.
- [ ] **Костюмы:** наступание на доступный стенд меняет аватар и Tool.
      Закрытый стенд не выдаёт героя. Снятие возвращает одежду/аксессуары;
      проверить R6/R15, повторный выбор и возрождение.
- [ ] **Оружие:** найденный предмет экипируется; пять улучшений показывают
      актуальную цену и характеристики. После пополнения кошелька кнопка обновляется.
      Быстрые повторные нажатия не списывают цену одной ступени дважды.
- [ ] **NPC:** обычный бандит и главарь преследуют вошедшего игрока и могут убить.
      Замах виден; уход из красной зоны уклоняет. Препятствие блокирует удар.
- [ ] **Главарь:** здоровье переводит бой через три фазы; волна и рывок совпадают
      с предупреждением. Победа выдаёт одну награду и запись BossDefeated.
- [ ] **Статусы:** способности замедляют/прерывают NPC на ограниченное время;
      после восстановления и возрождения статусы сбрасываются.
- [ ] **PvP:** оба вошли через портал — урон проходит; в городе, на обби,
      после выхода с арены, при защите возрождения и смерти — не проходит.
      За убийство игрока нет валютной награды.
- [ ] **Ящик:** появление, парашют, приземление и исчезновение корректны.
      Два клиента открывают одновременно — только один получает оружие.
      Прокрутка не меняет серверный результат; кнопка пропуска показывает тот же приз.
- [ ] **Дубликаты:** копии ограничены 99; компенсация не превышает лимит кошелька.
      Отключение победителя во время получения не выдаёт второй приз.
- [ ] **Обби:** последовательность 16 крыш, точки 4/8/12, падение, смерть,
      возврат к точке, ранний финиш и десятиминутный таймаут.
      Награда раз в пять минут; рекорд и победы сохраняются.
- [ ] **Меню на обби:** обычные окна не перекрывают управление маршрутом;
      команда владельца «Домой» отклоняется до выхода из обби.
- [ ] **Цели и титулы:** все семь заданий и восемь достижений используют реальные
      счётчики; повторный запрос не даёт приз снова. Бесплатный титул можно
      выбрать/скрыть; он не перекрывает VIP.
- [ ] **Ежедневная серия:** день 1–7, новый цикл, отказ до 24 часов,
      сброс после перерыва больше 48 часов, переполненный кошелёк без потери награды.
      Для проверки времени используйте отдельную тестовую конфигурацию.
- [ ] **Перерождение:** требования, подтверждение, ровно один сброс и один
      бонус дохода. Инвентарь, прокачка оружия, XP, задания, титулы и открытые
      герои сохраняются.

## Сохранения и конкуренция

- [ ] Изменить Coins/XP, построить дом, улучшить оружие, получить ящик, титул,
      ежедневный бонус и рекорд обби. Выйти и войти: все поля совпадают.
- [ ] Загрузить профиль предыдущей версии: валюты, дом, инвентарь, ступени,
      полученные задания сохранены; развитому игроку не навязывается обучение.
- [ ] Войти быстро после выхода и проверить конфликт сессии: нет дублирования
      или записи от прежнего сервера поверх новой.
- [ ] Выйти во время загрузки, сохранения и покупки; остановить сервер во время
      финальной записи. Повторный вход не сбрасывает прогресс.
- [ ] Проверить отказ загрузки и временный отказ записи в тестовом окружении:
      интерфейс показывает ошибку; последующая успешная запись сохраняет профиль.
- [ ] Одновременно запросить награду, повышение оружия и собирание копилки:
      итоговый баланс/инвентарь соответствуют только успешным серверным операциям.

## Robux, права и ресурсы

- [ ] При ID 0 нет платных кнопок. Studio-предпросмотр не выдаёт Marketplace-владение.
- [ ] С настоящими ID в тестовом experience проверить отмену, уже купленный
      пропуск, продажу/недоступность API и повторный вход. Успех подтверждает Roblox.
- [ ] Обычный игрок не может использовать AdminRequest, в том числе подменой
      локального IsGameAdmin. Для группы ранг 254 не подходит, 255 подходит.
- [ ] Проверить материалы, рисунки костюмов, встроенные частицы и звуки в
      опубликованном клиенте; недоступный звук не ломает действия.
- [ ] Проверить права на имена, символы, образы, страницу и изображения пропусков
      либо подготовить отдельную оригинальную художественную версию.

## Нагрузка и критерии выпуска

Проверить **шесть трёхэтажных домов**, всех активных NPC, одновременный бой,
падающий ящик и обби. Сравнить High/Low/Off на настоящем ПК и телефоне.
Собрать frame time, CPU/GPU, память, сетевой трафик и число локальных эффектов
через Developer Console/MicroProfiler. Проверить, что после повторных смертей,
покупок и закрытия меню память и число обработчиков не растут постоянно.

Геометрия выросла с 404 до 704 закреплённых Parts для пустой карты и
с 1 472 до 2 222 для шести готовых домов. Эти числа не гарантируют FPS.
Целевые показатели согласуются после реального замера.

Публичный доступ открывается, когда обязательные проверки пройдены,
нет ошибок Output и потерь сохранений, права на оформление подтверждены,
реальные ID/продажи настроены при необходимости. До этого сборка остаётся
обновлением для испытаний.
